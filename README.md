# Portfolio Simón SFLA - Periodista Digital

Sitio web profesional tipo portafolio, moderno, minimalista y limpio.

## 🚀 Tecnologías

- **React 18** - Biblioteca de UI
- **Vite** - Build tool y dev server
- **CSS Vanilla** - Estilos personalizados minimalistas

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm build
```

## 🎨 Características

- ✅ Diseño minimalista y profesional
- ✅ Animaciones suaves al hacer scroll
- ✅ Navegación sticky con smooth scroll
- ✅ Carrusel auto-scroll de herramientas
- ✅ Responsive design
- ✅ 10 secciones completas
- ✅ Componentes React modulares

## 📂 Estructura del Proyecto

```
src/
├── components/
│   ├── Navbar.jsx       # Navegación sticky
│   ├── Hero.jsx         # Sección principal
│   ├── Services.jsx     # Servicios (3 columnas)
│   ├── Tools.jsx        # Carrusel de herramientas
│   ├── LinkedIn.jsx     # Conexión LinkedIn
│   ├── Approaches.jsx   # Enfoques de proyecto
│   ├── Projects.jsx     # Showcase de 6 proyectos
│   ├── Pyme.jsx         # Sección para PYMEs
│   ├── Claim.jsx        # Claim final
│   └── Footer.jsx       # Footer con contacto
├── App.jsx              # Componente principal
├── main.jsx             # Entry point
└── index.css            # Estilos globales
```
